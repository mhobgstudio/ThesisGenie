Creating Presentations with Gamma

Gamma (gamma.app) is an AI-powered presentation tool that creates professional slides from a text prompt. It's perfect for thesis defenses, class presentations, and conference talks.

How to Use Gamma

  1. Go to gamma.app and sign up (free tier available)
  2. Click "New with AI" and choose "Presentation"
  3. Describe your topic: e.g., "A thesis defense presentation on the impact of mobile money on small businesses in Ghana"
  4. Gamma generates a complete slide deck — edit as needed
  5. Export as PDF or PowerPoint
💡 Tip: Gamma works best with specific prompts. Instead of "presentation on AI," try "20-slide presentation on AI detection methods in academic writing, targeting PhD students at KNUST."

LaTeX with AI

LaTeX is the standard for academic papers, especially in STEM fields. AI can generate LaTeX code from plain English descriptions.

The LaTeX Prompt

Write the LaTeX article code for the above content.
Note: Don't output in canvas.
Simplify the code so a simple compiler can run it — nothing fancy.
Include:
- Title, author, abstract
- Proper section structure
- Bibliography with placeholder references
- Standard formatting

Compiling LaTeX

Use the LaTeXGPT Chrome Extension to compile LaTeX directly in your browser:

  1. Install from Chrome Web Store: search "LaTeXGPT"
  2. Paste the generated LaTeX code
  3. Click compile — get your PDF

Alternatively, use online compilers like overleaf.com (free for students).

Generating Slides with SciSpace

SciSpace (scispace.com) lets you explore research papers and generate summaries, explanations, and even presentation content from them.

Creating Diagrams & Flowcharts

Use AI to generate Mermaid diagram code:

Generate a Mermaid flowchart for the following process:
1. Student submits thesis via TDMS
2. System assigns internal and external examiners
3. Examiners review and submit reports
4. Supervisor reviews reports and provides feedback
5. Student makes revisions if needed
6. Graduate school approves for congregation

Then paste the Mermaid code into any Markdown renderer or mermaid.live to see the diagram.

💡 Tip: For your thesis, use Mermaid for process flows, concept maps, and system architectures. It's version-controllable (unlike images) and easy to update.
