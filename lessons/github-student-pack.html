What's in the Student Developer Pack?

The GitHub Student Developer Pack gives students free access to 100+ developer tools and services, including:

  • GitHub Copilot — AI pair programmer (normally $10/month)
  • Azure DevOps — CI/CD and project management
  • DigitalOcean — $200 in cloud credits
  • Namecheap — Free .me domain for 1 year
  • JetBrains — Free IDE licenses (IntelliJ, PyCharm, etc.)
  • Many more...

Step-by-Step: Apply for the Pack

  1. Visit education.github.com/pack
  2. Sign up or sign in to GitHub
  3. Click "Get Student Developer Pack"
  4. Add your school email: username@st.knust.edu.gh
  5. Verify your email (see detailed steps below)
  6. Enter school name: "Kwame Nkrumah University of Science and Technology"
  7. Answer usage questions about how you plan to use the tools
  8. Upload proof if requested (student ID or admission letter)
  9. Submit — approval usually takes 1-5 business days

Email Verification: The Critical Step

This is where most KNUST students get stuck. Here's the exact process:

Step A: Add Email to GitHub

  1. Log in to GitHub → click your avatar → Settings → Emails
  2. Under "Add email address", enter username@st.knust.edu.gh
  3. Click "Add"
  4. Click "Resend verification email" next to that address

Step B: Check KNUST Outlook

  1. Go to outlook.office.com
  2. Log in with username@st.knust.edu.gh and your KNUST password
  3. Check your Inbox, Spam/Junk, and any filters
  4. Open the email from noreply@github.com
  5. Click the "Verify email" link
💡 Tip: If the verification email doesn't arrive within 5 minutes, click "Resend verification email" on GitHub again. Also check that your KNUST mailbox can receive external emails.

Troubleshooting

  • Email not arriving? — Contact KNUST IT/ICT to unblock messages from github.com
  • Mailbox not working? — Visit UITS at Casely Hayford Block or submit a ticket at helpdesk.knust.edu.gh
  • Application rejected? — Reapply with proof of enrollment (student ID, admission letter)
  • Need password reset? — Visit apps.knust.edu.gh/students/Account/ForgotPassword

After Approval: Install Copilot

In VS Code:

  1. Install VS Code from code.visualstudio.com
  2. Install the GitHub Copilot extension
  3. Sign in with your GitHub account
  4. Start coding — Copilot suggests completions as you type

In Terminal (Copilot CLI):

winget install GitHub.Copilot
mkdir TerminalProjects
cd TerminalProjects
copilot
