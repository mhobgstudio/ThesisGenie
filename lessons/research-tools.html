Tool Overview

Each research tool has strengths. Use the right tool for the right task:

Perplexity (Premium Education Package)

An AI-powered search engine that provides answers with cited, clickable sources.

Best For

  • Quick literature discovery
  • Understanding the state of the art on any topic
  • Getting cited answers you can verify

How to Use

  1. Go to perplexity.ai
  2. Type your research question in plain English
  3. Perplexity searches the web and provides a cited answer
  4. Click on sources to verify and read the original papers

Research Rabbit

A free tool that discovers related papers through citation mapping.

Best For

  • Discovering papers you didn't know existed
  • Mapping the citation network around a key paper
  • Finding the most influential papers in a field

How to Use

  1. Go at researchrabbit.ai
  2. Add a paper you already know (by title, DOI, or URL)
  3. Research Rabbit shows related papers via citation connections
  4. Explore the visual map to find clusters of related work
💡 Tip: Start with 2-3 key papers from your field. Research Rabbit will map out the entire citation network, revealing papers you'd never find through manual searching.

Brave Search

An ad-free, privacy-focused search engine. Good for finding resources without tracking.

Best For

  • Quick, clean search results without ads
  • Academic and technical searches
  • Finding PDFs and open-access papers

sciSpace

Interact with research papers — ask questions, get explanations, find related work.

Best For

  • Understanding complex papers
  • Getting plain-language explanations of technical content
  • Finding related papers

DeepSeek

A powerful AI model with strong technical and scientific capabilities. Free to use.

Best For

  • Analyzing technical content
  • Generating research summaries
  • Code analysis and explanation

Recommended Workflow

  1. Start with Perplexity — Get an overview of your topic with cited sources
  2. Use Research Rabbit — Take the best papers and map their citation networks
  3. Use sciSpace — Deep-dive into specific papers you don't fully understand
  4. Use Brave Search — Find open-access versions of paywalled papers
  5. Use DeepSeek — Generate summaries and analysis of your collected literature
💡 Tip: No single tool does everything. The power comes from combining them in a systematic workflow.
